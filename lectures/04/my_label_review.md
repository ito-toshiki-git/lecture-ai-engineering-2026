# 自作10問の回答と比較用判定の根拠

実際に生成された回答と，比較用の判定の根拠をまとめた資料である．比較用の判定は，モデルによる自動採点の結果を見る前に固定し，今回の評価に採用した．

「根拠・範囲・ヒント・分かりやすさ・回の表示」の順に判定する．独立した人による再採点は未実施である．

## my01 正常系

**質問**：PEFTとは何ですか．正式名称と，何を節約できるのかを初心者向けに教えてください．

**実際の回答**

**PEFT**（ペフト）とは、Parameter-Efficient Fine-Tuning（パラメータ効率の良いファインチューニング）の略で、日本語では「**効率的なパラメータ微調整**」という意味です。

AIモデル（大規模言語モデルなど）全体をトレーニングするのではなく、**ごく一部のパラメータや新しく追加した小さなパラメータだけを学習する手法の総称**です。

---

### 何を節約できるのか？（初心者向け）

AIモデルを私たちの目的に合わせて賢くし直す（ファインチューニングする）とき、通常はモデルのすべての部分を書き換えるため、非常に大きなお金と高い性能を持つグラフィックボード（GPU）が必要です。

しかし、PEFTを使うと以下の2つを**大きく節約**できます。

1. **必要なGPUメモリ（VRAM）**
   - 学習させるパラメータの数がぐっと減るため、一般的なパソコンのGPUや、安価なクラウド環境でも学習ができるようになります。
2. **モデルの保存容量（ディスク容量）**
   - モデル全体を何度も保存する必要がなく、追加した小さな部分（アダプタと呼ばれるファイルなど）だけを保存すればよいため、ファイルサイズを非常に小さく抑えられます。

（第2回）

## my03 誤った前提

つまり、全パラメータではなく**追加された小さなパラメータだけを更新する**仕組みとなっています。

## my04 複数用語

**質問**：量子化と追加学習は，どちらもモデルを小さくする同じ操作ですか．違いを二つの文で教えてください．

**実際の回答**

量子化と追加学習（ファインチューニング）は、どちらもモデルの調整に使われますが、同じ操作ではありません。

量子化は、モデルの重みを少ないビット数で表現し直すことで、精度を少し代償にしつつメモリ使用量や計算量を減らす技術です。一方、追加学習は、特定のデータを使ってモデルを再学習させ、特定のタスクへの適応や指示に従う振る舞いを身につけさせる手法です。（第2回）

**比較用判定**：pass / pass / pass / fail / pass

**理由**：量子化と追加学習の区別は正しい．二つの文という依頼に対して，違いの説明に加えて冒頭の一般的な一文を置き，本文三文となったため分かりやすさを不合格とした．判断の境目として迷いあり．
